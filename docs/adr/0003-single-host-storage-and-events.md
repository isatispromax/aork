# 领域表为权威状态，单库事务维护事件和命令

2026-11-15：首版选择单个本地 SQLite WAL 数据库与单 Host 写入口，领域表保存权威状态，状态、命令回执及 durable event 在短事务中提交。插件拥有各自表，事务通过明确的同步参与接口协调；不采用每插件独立数据库，也不要求重放全部事件才能恢复工作台。

ACP 和进程操作在事务外执行。外部交付无法与数据库提交原子化，尝试发送后发生崩溃的操作标记为交付不确定，不自动重发。浏览器通过一致快照和有序事件重连；原生 Agent 历史单独保存，不能由工作台事件替代。

代价是首版限定单机存储，并且必须实现命令去重、消费 offset、快照水位和整批备份。需要多机并发写入时重新评估数据库与调度架构，而不是将 SQLite 文件放到共享网络盘。详见[架构基线](/Users/yangdi/code/multai/Aork/.scratch/plugin-ai-workbench/technical-architecture.md)。
