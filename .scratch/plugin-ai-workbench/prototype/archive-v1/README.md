# Aork 界面交互原型

这是可丢弃的交互评审代码，使用内存中的示例数据。刷新重置，不连接真实 Agent、服务器、认证或数据库。

验证问题：项目、会话、待处理与产物如何组织，才能让用户清楚找到工作、处理请求并继续执行？

三个布局共用相同数据与行为，通过 `?variant=A`、`?variant=B`、`?variant=C` 切换：

- A：项目工作台。项目和会话常驻左侧，右侧查看资料与产物。
- B：待处理优先。先浏览需要关注的工作，再在详情区域处理交互。
- C：会话专注。以对话为中心，项目、会话和产物按需展开。

双击本目录的 index.html 即可打开。也可从仓库根目录启动：

```sh
python3 -m http.server 4317 --bind 127.0.0.1 --directory .scratch/plugin-ai-workbench/prototype
```

然后访问 http://127.0.0.1:4317/ 。原型控制条支持布局切换、模拟关键状态、重置和查看状态。

建议评审：新建项目/会话 → 选择工作区与 Agent → 发送与排队 → 回答权限/表单 → 区分停止本轮和结束运行 → 查看/复用产物 → 处理失效请求与中断恢复 → 检查插件启停。

当前尚未获得交互确认。工单 01 只有在用户明确确认后才能完成；正式功能开发从后续工单开始。原型代码不直接晋升为生产代码。

本目录目前位于尚未初始化 Git 的设计工作区中，作为独立原型保留；交互确认后再记录结论与实现指针，不声称已提交到原型分支。
