# 28: 完成无 Git 的资料处理工作流

**What to build:** 通过独立研究或文档插件，在普通目录读取资料、生成带来源结果，并预览、下载和再次使用。

**Blocked by:** 24: 让 Agent 调用选定的工作台工具, 26: 可扩展且隔离的产物预览, 27: 复用成果与关联新会话

**Status:** ready-for-agent

- [ ] 在空白隔离验收实例的初始 profile 装入独立包，遵守早期安装限制；对已有工作台新增能力由完整维护安装及插件替换工单验收。
- [ ] 完成一个明确的最小研究/文档场景：使用已有工作区资料生成带来源的摘要或文档，不另加网络搜索服务或全套办公格式要求。
- [ ] Plugin 只使用公共 Workspace、Session、工具与 Artifact 契约，不修改会话内核或 Agent 接入代码。
