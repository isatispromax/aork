# 09: 管理 Agent Profile 与服务器凭据引用

**What to build:** 用户保存 Agent Profile、查看 Provider 可用性和凭据状态，已有服务器秘密不会回传浏览器。

**Blocked by:** 07: 创建项目与普通目录工作区

**Status:** ready-for-agent

- [ ] 注册通用 Provider 契约并用可控 ACP 测试 Provider 验证配置保存、检测结果和不可用原因；两个真实 Provider 分别实现。
- [ ] Profile 保存经校验的 Provider、参数、版本要求、状态目录和凭据引用，不接受浏览器任意启动命令。
- [ ] 手动 API 凭据加密落盘，主密钥独立配置；原生 OAuth 状态只承诺受限目录保护，查询与诊断不返回已有明文。
- [ ] 复用项目/工作区工单已建立的公共命令回执、短事务和事件原语；重启后可读取脱敏配置，重复命令不重复创建 Profile，编辑不能静默更改既有 Run 快照。
- [ ] 缺密钥、缺二进制或失效凭据引用具有可见错误；通过真实存储和公开设置页面验证，不将测试 Provider 视为真实 Agent 接入。

规格用户故事：2, 11, 12, 67。

验收共识：遵循正式规格、领域词汇与已接受 ADR（含全界面公开替换契约 ADR-0004）；使用真实 Host、插件和持久化，经浏览器或公开命令/查询/事件及维护入口验证外部行为。ACP 协议替身仅用于外部 Agent 与故障控制，真实 Agent 验收不得被替代。
