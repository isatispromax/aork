# 33: 恢复匹配批次并校验外接目录

**What to build:** 从一致备份恢复工作台，浏览器可查看原历史与产物；外接目录不匹配时明确阻止自动执行。

**Blocked by:** 32: 生成完整工作环境的一致备份

**Status:** ready-for-agent

- [ ] 在停止的 Host 上验证并恢复匹配数据库、配置、Plugin 版本、原生状态、托管文件和产物引用，拒绝混用不一致批次。
- [ ] 验证凭据引用及对应独立主密钥可用，缺少或不匹配时明确阻止相关 Provider 启动；不通过记录明文秘密来伪造可恢复性。
- [ ] 恢复后的 Host 使用新的 streamId 和连接代次，旧卡片/游标失效，未完成输入和队列不自动执行。
- [ ] 外接目录缺失、映射变化或内容校验不一致时要求显式修复或使用当前目录重新开始，不静默覆盖目录。
- [ ] 恢复后通过浏览器查询历史、下载指定 Artifact 版本和验证工作区文件，登录及授权仍有效。
- [ ] 以损坏/缺失批次和外部目录差异验证失败路径；只有真实 Agent 的能力与原生状态满足且实际续聊通过时才声称可原生恢复。

规格用户故事：40, 64, 65。

验收共识：遵循正式规格、领域词汇与已接受 ADR（含全界面公开替换契约 ADR-0004）；使用真实 Host、插件和持久化，经浏览器或公开命令/查询/事件及维护入口验证外部行为。ACP 协议替身仅用于外部 Agent 与故障控制，真实 Agent 验收不得被替代。
