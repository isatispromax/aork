# 02: 默认插件启动与受保护入口

**What to build:** 从可复现的构建启动最小 Host，浏览器看到默认插件贡献的登录入口和启动诊断，未初始化时拒绝业务访问。

**Blocked by:** 01: 界面交互原型与用户确认

**Status:** claimed

- [ ] 按既定技术基线锁定依赖，提供可重复构建、启动、类型检查与行为测试入口；本票不建立完整业务模块或安装器。
- [ ] 默认认证与 workbench 通过最小 SDK 激活作用域注册服务和视图，内核不导入业务实现，公开 SDK 不暴露 Cordis、Fastify 或数据库内部对象。 SDK 初期保持 0.x，架构验证门槛通过前不承诺长期稳定兼容。
- [ ] 建立版本化 UI 契约注册与独占提供者选择原语；默认登录和主布局由 profile 显式选择的插件提供，组合布局通过公开子视图接口挂载。正常业务 UI 不进入 apps/web／kernel；本票建立机制，不提前实现后续会话等业务。
- [ ] Shell 仅负责引导、加载、权限强制和最小启动／错误兜底；缺少提供者时显示具体故障与本地维护路径，不出现宿主硬编码的正常登录、设置或工作台。
- [ ] Host 启动取得单实例锁，同一数据实例的第二个 Host 被拒绝；后续服务沿用这一入口，不能等到真实运行后才补防重复启动。
- [ ] 保存并读取默认 profile 与启动配置，重启后使用相同版本组合；静态清单先校验再执行入口。
- [ ] 浏览器加载真实 Host 提供的引导和诊断；缺少账号或认证能力时不开放业务接口，启动失败给出可定位错误。
- [ ] 通过启动命令和浏览器验收；默认组合的启动成功不被称为已支持独立插件安装。

规格用户故事：55, 68, 69, 73, 75, 76, 77, 78。

验收共识：遵循正式规格、领域词汇与已接受 ADR（含全界面公开替换契约 ADR-0004）；使用真实 Host、插件和持久化，经浏览器或公开命令/查询/事件及维护入口验证外部行为。ACP 协议替身仅用于外部 Agent 与故障控制，真实 Agent 验收不得被替代。
