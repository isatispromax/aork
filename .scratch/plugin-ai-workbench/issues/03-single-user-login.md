# 03: 访问 Token 与浏览器会话

**What to build:** 参照 dsh，以服务器进程生成的随机启动 Token 链接进入工作台，换取受保护的浏览器会话；不提供用户名、密码或 Token 输入表单。保留 Aork 的当前浏览器退出与本地认证恢复能力。

**Blocked by:** 02: 默认插件启动与受保护入口

**Status:** claimed

- [ ] 每个 Host 进程生成 32 字节随机启动 Token（base64url），仅在本地启动输出中提供 `/?token=…` 访问链接；不提供用户名、密码、账号初始化或 Token 输入表单。Token 不进入公共 bootstrap、诊断、错误或请求 URL 日志。
- [ ] 仅精确根路径的 GET 接受启动 Token，常量时间比较成功后换取签名 HttpOnly、SameSite=Strict Cookie，并以 303 跳转到清除 Token 的 URL；生产使用 Secure，明文开发模式必须显式限制在 loopback。错误／缺失 Token 不授予业务访问，查询、命令和 WebSocket 不接受启动 Token 绕过入口。
- [ ] 独立签名密钥和稳定的单实例主体持久化，浏览器会话默认 30 天；重启轮换启动 Token，但未过期有效 Cookie 可继续使用。Aork 另保留持久的每浏览器会话撤销，退出后刷新／重启仍不得访问，容量边界不得破坏已有有效会话。
- [ ] HTTP 命令和查询由宿主强制授权，状态变更校验 CSRF，WebSocket 以 Cookie 认证并校验 Origin／来源；保留限流与拒绝访问行为。Token 交换也遵守适用的来源边界，不照搬 dsh 的中间件顺序削弱现有校验。
- [ ] 认证插件故障时保持拒绝访问，同锁的本地访问恢复／签名密钥轮换可修复配置并撤销旧浏览器授权；公网不存在匿名管理、密钥恢复或 Token 读取入口。签名密钥与 Agent 凭据不回传浏览器。
- [ ] 未授权提示页和退出控件使用公开认证 UI 契约，profile 可选择不同提供者；提示使用终端访问链接，不增加账号或 Token 表单。UI 替换不改变服务端会话、CSRF、Origin 或授权规则；认证失效后清除受保护缓存并撤销订阅。仅认证 UI 故障不撤销其他有效浏览器或停止 Run。
- [ ] 通过真实 Host／持久化、本地启动输出、Token 链接及浏览器验证正确／错误 Token、URL 清理、重启、退出、非法来源、认证故障与 UI 替换。延迟 bootstrap／状态／退出响应不得覆盖新授权 Cookie；不以旧用户名／密码检查作为本票通过证据。

规格用户故事：1, 66, 67, 75, 78。

验收共识：遵循正式规格、领域词汇与已接受 ADR（含全界面公开替换契约 ADR-0004）；使用真实 Host、插件和持久化，经浏览器或公开命令/查询/事件及维护入口验证外部行为。ACP 协议替身仅用于外部 Agent 与故障控制，真实 Agent 验收不得被替代。
