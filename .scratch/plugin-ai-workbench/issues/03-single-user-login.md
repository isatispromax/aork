# 03: 初始化账号与登录登出

**What to build:** 在服务器创建唯一工作台账号，浏览器登录受保护页面并登出，认证故障可通过本地入口修复。

**Blocked by:** 02: 默认插件启动与受保护入口

**Status:** ready-for-agent

- [ ] 服务器 CLI 初始化账号，密码使用参数化 scrypt 哈希；公网不存在匿名初始化或恢复入口。
- [ ] 服务端持久化登录会话，生产浏览器 Cookie 使用 Secure、HttpOnly、SameSite；登录与登出跨页面刷新有效。
- [ ] HTTP 命令和查询由宿主强制身份校验，状态变更校验 CSRF，WebSocket 握手校验 Origin；登录限速。
- [ ] 认证插件故障时保持拒绝访问，本地恢复命令可修复配置；浏览器不会读到密码哈希、会话密钥或服务器凭据。
- [ ] 登录／登出界面使用公开认证 UI 契约，profile 可选择不同 UI 提供者；展示通过公开认证命令完成，替换 UI 不更改服务端会话、CSRF、Origin 或限速规则，默认登录页不硬编码在 Shell。
- [ ] 认证失效后撤销受保护订阅并清除对应查询缓存；重新显示所选登录 UI。认证／授权服务缺失或故障时拒绝业务访问；仅登录 UI 故障时显示错误与本地维护路径，未认证用户不可绕过认证，但不因此撤销其他有效登录会话或停止 Run。
- [ ] 通过真实存储、公开登录接口与浏览器验证正确/错误登录、登出后访问、非法来源和认证故障。

规格用户故事：1, 66, 67, 75, 78。

验收共识：遵循正式规格、领域词汇与已接受 ADR（含全界面公开替换契约 ADR-0004）；使用真实 Host、插件和持久化，经浏览器或公开命令/查询/事件及维护入口验证外部行为。ACP 协议替身仅用于外部 Agent 与故障控制，真实 Agent 验收不得被替代。
