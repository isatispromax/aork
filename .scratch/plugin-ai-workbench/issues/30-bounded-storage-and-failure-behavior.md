# 30: 存储故障、数据保留与慢客户端诊断

**What to build:** 日志和事件有明确边界，磁盘或关键持久化失败时用户看到受阻原因，不把易失结果当成成功保存。

**Blocked by:** 14: 浏览器断线后的状态恢复, 24: 让 Agent 调用选定的工作台工具, 25: 登记、预览和下载产物版本

**Status:** ready-for-agent

- [ ] 落实事件/诊断的大小与保留窗口，原始协议只留必要脱敏字段，大文件通过 Artifact 或文件引用；不把默认调优值宣称为实测性能。
- [ ] 过期 cursor 通过既有 resync 路径恢复，慢客户端断开后可查询已保存状态；消息批次有界。
- [ ] 在真实 Host/存储故障条件下停止接单并终止或阻断受影响 Run，未确认停止的文件工具仍保持 Claim；基础工单中的拒绝不安全状态行为不可被推迟到本票。
- [ ] 部分流、文件登记或工具结果持久化失败不会被显示为成功；已有保存内容和来源仍可查询。
- [ ] 用受控磁盘/写入失败、慢消费者和保留窗口验证公开行为，并检查事件及默认诊断不泄露认证载荷或已有凭据。

规格用户故事：17, 21, 35, 67。

验收共识：遵循正式规格、领域词汇与已接受 ADR（含全界面公开替换契约 ADR-0004）；使用真实 Host、插件和持久化，经浏览器或公开命令/查询/事件及维护入口验证外部行为。ACP 协议替身仅用于外部 Agent 与故障控制，真实 Agent 验收不得被替代。
