# 12: 完成文本执行轮次并随时取消

**What to build:** 用户发送文本，看到持久化流式回答和工具报告，并能在长 prompt 中取消；完成后可继续下一轮。

**Blocked by:** 11: 准备与结束运行，落实工作区占用

**Status:** ready-for-agent

- [ ] 输入、Turn、用户消息和回执先持久化；副作用前记录 attempting，返回受理与执行成功分开；一次 Session 最多一个 prompt，本票运行中新增输入明确拒绝而不偷偷并发。
- [ ] 文本有界落库后推送，工具报告只呈现不重复执行；无真实费用或用量数据时显示未知。
- [ ] 长 prompt 不阻塞控制操作；取消先关闭新响应通道，显示 cancelling 直到真实终止，超时使用既有受管停止；取消 Turn 不自动释放仍活跃 Run 的 Claim。
- [ ] 区分发送窗口缺少确定交付结果与已知执行中的连接中断，按事实显示 delivery_unknown 或 interrupted 并保留停止原因，两者都不自动重发；关键写入失败停止接单并阻断或终止受影响 Run。
- [ ] 通过 Runtime 持久事实建立 interactions 所有的最小 pending 投影，按 run/generation 关联并展示等待和取消；投影更新与消费 offset 同事务提交。本票不提供批准/拒绝入口，不自动或超时批准，后续权限工单补充响应。
- [ ] 浏览器关闭不会结束 Run；用 ACP 替身经完整 Host 验证成功、工具报告、取消、等待权限和发送窗口故障。

- [ ] composer、消息和工具状态均通过公开可替换 UI 契约提供，输入／取消只调用 sessions 公开命令；替换呈现不得重复提交、猜测完成、放行并发 prompt 或绕过服务端运行约束。

规格用户故事：3, 16, 17, 20, 21, 23, 25, 31, 32, 74。

验收共识：遵循正式规格、领域词汇与已接受 ADR（含全界面公开替换契约 ADR-0004）；使用真实 Host、插件和持久化，经浏览器或公开命令/查询/事件及维护入口验证外部行为。ACP 协议替身仅用于外部 Agent 与故障控制，真实 Agent 验收不得被替代。
