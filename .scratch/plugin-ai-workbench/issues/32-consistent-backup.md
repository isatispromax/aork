# 32: 生成完整工作环境的一致备份

**What to build:** 维护者在写入停止后生成带版本和校验清单的备份批次，明确哪些外接目录没有包含。

**Blocked by:** 25: 登记、预览和下载产物版本, 31: 维护前停止接单并确认全部运行结束

**Status:** ready-for-agent

- [ ] 复用维护门禁，确认全部相关写入停止后使用 SQLite backup 接口，不复制运行中的主数据库冒充一致备份。
- [ ] 同批保存数据库、可恢复的 Plugin 归档/构建产物本身及精确版本、实际 Profile/插件配置、凭据密文与引用、原生 Agent 状态、托管 Workspace 和 Artifact，记录完整性清单；主密钥仍独立配置并明确恢复依赖，不把只有版本号或密文称为完整可恢复环境。
- [ ] 外接目录仅登记路径映射、访问范围、内容校验和未包含标记，不静默复制或覆盖外部目录。
- [ ] 备份中任一文件缺失、读写失败或空间不足使整批结果明确失败；维护状态不能在备份完成前重新接单。
- [ ] 通过公开 CLI 备份含真实业务数据的测试实例并验证清单与结果；原生续聊能力留到恢复及真实 Provider 验收，不仅凭文件存在下结论。

规格用户故事：64, 65。

验收共识：遵循正式规格、领域词汇与已接受 ADR（含全界面公开替换契约 ADR-0004）；使用真实 Host、插件和持久化，经浏览器或公开命令/查询/事件及维护入口验证外部行为。ACP 协议替身仅用于外部 Agent 与故障控制，真实 Agent 验收不得被替代。
