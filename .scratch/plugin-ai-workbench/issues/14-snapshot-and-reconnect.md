# 14: 浏览器断线后的状态恢复

**What to build:** 用户刷新、断网或慢连接后恢复已保存的会话状态，时间线不丢失、不重复。

**Blocked by:** 12: 完成文本执行轮次并随时取消

**Status:** ready-for-agent

- [ ] 公开查询提供一致读快照中的 snapshot、streamId、cursor，WebSocket 从数据库补读后续序号，避免回放与通知交界丢失。
- [ ] 序号按十进制字符串传输，客户端只推进已应用 cursor 并按事件 ID 幂等合并；异步投影使用自己的事件或已应用水位。
- [ ] Host 新启动更换 streamId，游标过旧、备份恢复或保留窗口失配要求重新同步；不能无限重放所有历史。
- [ ] 慢客户端缓存有界，超过范围断开并提示重新连接；未落库内容不能表现为已保存，订阅受身份与 Origin 校验。
- [ ] 在公开边界构造快照交界写入、投影落后、连接断开和慢消费者，浏览器恢复结果与持久查询一致。

规格用户故事：3, 35。

验收共识：遵循正式规格、领域词汇与已接受 ADR（含全界面公开替换契约 ADR-0004）；使用真实 Host、插件和持久化，经浏览器或公开命令/查询/事件及维护入口验证外部行为。ACP 协议替身仅用于外部 Agent 与故障控制，真实 Agent 验收不得被替代。
