# 08: 浏览和操作工作区文件

**What to build:** 用户在已授权工作区浏览文件、上传资料、进行基本编辑并下载结果。

**Blocked by:** 07: 创建项目与普通目录工作区

**Status:** claimed

- [ ] 文件页面通过工作区稳定身份调用公开文件服务；路径解析遵循真实目录访问范围，拒绝越界或通过目录别名绕过边界。
- [ ] 上传、下载与基本文本写入形成完整浏览器路径，失败展示具体原因，不把大内容塞进事件流。
- [ ] 文件写入统一经过 workspace 服务的写入许可入口，为 Run 占用接入留下明确服务契约；未知所有者状态不得放行。
- [ ] 文件浏览不自动登记 Artifact，不将目录现有文件归因于某个 Agent。
- [ ] 用真实目录和公开文件操作验证持久结果、拒绝越界、失败处理及刷新后的可见性；后续 Run 工单必须接通并验证写入占用。

- [ ] 文件浏览／编辑视图通过公开 UI 契约提供，可替换布局与操作呈现；仅调用 workspace 公开文件接口，目录范围和写入许可仍由服务端强制。

规格用户故事：8, 74。

验收共识：遵循正式规格、领域词汇与已接受 ADR（含全界面公开替换契约 ADR-0004）；使用真实 Host、插件和持久化，经浏览器或公开命令/查询/事件及维护入口验证外部行为。ACP 协议替身仅用于外部 Agent 与故障控制，真实 Agent 验收不得被替代。
