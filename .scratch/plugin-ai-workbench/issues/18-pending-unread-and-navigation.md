# 18: 全局待处理、未读与工作台导航

**What to build:** 用户跨项目处理有效 Interaction，分别查看未读回复，刷新后恢复当前会话和布局。

**Blocked by:** 14: 浏览器断线后的状态恢复, 16: 按协商能力回答结构化问题

**Status:** ready-for-agent

- [ ] 全局待处理列表、计数、跳转和响应来自 interactions 的公开投影；普通问句、已完成回复和失效请求不进入列表。
- [ ] 完成回复维护独立未读位置，打开对应内容后推进已读游标；其他会话和未打开内容的未读不被顺带清除。
- [ ] 整体布局、侧栏、页头、首页、项目／工作区页、会话列表和当前主视图由 profile 选择的公开 UI 提供者装配，URL 恢复实体选择，布局偏好持久化；复用最小引导和错误边界，不将这些业务界面写入 Shell。

- [ ] 菜单与通知呈现也可替换；导航项、菜单项、工具栏和通知来源支持稳定排序／显隐，主题、token 和语义图标保持统一。隐藏待处理入口不改变 Interaction 的真实状态和有效性。
- [ ] 复用查询缓存与事件接口，跨标签页更新正确；Plugin 视图失败局部呈现，运行结束不靠前端计时器猜测。
- [ ] 浏览器验证跨项目请求、普通完成回复、阅读、刷新和局部视图故障；原生历史回放不得产生新未读，由恢复工单扩展验证。
