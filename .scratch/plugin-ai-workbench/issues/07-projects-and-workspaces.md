## Answer

工作区 Plugin 通过公开 `@aork/contracts/workspace` 和 `aork.workspace.browser@1` 提供 Project／Workspace 的创建、编辑、导航与归档。独立 UUID 保持身份；项目包含多个工作区。托管目录与用户明确授权的外接目录分别记录管理方式、请求路径、真实路径、读写范围和 device/inode。表、迁移、Drizzle 编译及领域不变量全部属于 workspace；Host／kernel 不导入业务实现。默认 workbench 使用公开子视图装配项目树、表单及真实目录详情，无示例项目、会话或文件数据。

公开命令包含 commandVersion，身份＋commandId 唯一。原始 JSON 载荷按对象键排序后，与命令名／版本一起形成不可变指纹；业务 trim／默认值不掩盖不同输入。已接受命令在目录准备之前返回原回执，重复及并发请求只提交一次，内容或版本变化返回冲突。Token 本地恢复保持稳定主体，旧回执继续有效。公开查询、回执读取及有界事件检查均保持 Cookie／CSRF／Origin／图版本边界。

SDK 提供绑定到所属 Plugin 的预声明语句和不透明同步事务；插件获得不到 driver／Drizzle 对象。共享同库 token 仅经显式语义服务传递，供后续跨插件参与使用。SELECT 读取与事务内 DML 分开，拒绝 RETURNING 冒充读取；过期／异库 token 不可使用。合法含点或连字符的 Plugin ID 通过注入式编码获得互不碰撞的命名空间。目录 I/O 在事务外；状态、校验后的结果、脱敏事件及完整回执在一个 SQLite WAL／外键／FULL 短事务中提交。序号以持久十进制字符串提供，浏览器事件不含主体、Cookie 或认证载荷。

验证环境为 macOS 27.2.1／26B131 arm64、Node 24.22.3 ABI137、pnpm 10.30.2。合入 04 后 frozen install、build、严格 typecheck、边界检查、diff 检查通过；完整 Vitest **49/49**、实际 Chromium 浏览器 **15/15** 通过。其中本票 11 个公开 Host 测试与 2 个浏览器工作流覆盖：非 Git 目录、路径别名／替换／错误目录、托管目录、多个工作区、编辑／归档保留目录、刷新及重启、精确回执重放与冲突、Token 恢复后去重、事件分页和大十进制游标、无效 Plugin 结果回滚、异步事务参与者拒绝且 Host 不崩溃、含点／连字符 Plugin 的独立数据。

真实 OS `RLIMIT_FSIZE` 造成 SQLite 写入故障时，公开命令返回 503，查询及事件仅保留先前接受的记录，失败 ID 没有回执；新写入停止，重启后可安全重试。此测试用 python3 配置环境限制，没有产品故障后门。独立 Chrome157 手工验证创建、URL 恢复、真实托管路径、归档与目录仍存在；无页面错误，截图 `/tmp/aork-ticket07-parent-workspace.png`。数据库与 TypeScript 独立审查发现的读取模式、故障后在途事务、索引所有权、异步拒绝和命名空间问题均已修复并经过相应公开行为回归。

公开接口和限制见[项目与工作区说明](/Users/yangdi/code/multai/Aork/docs/workspace/projects-and-workspaces.md)。管理目录在数据库失败后可能保留未引用的准备目录；外接目录不会因回滚被删除。文件／Git／Session／Run／Claim、WebSocket 一致快照重连、目录回收、Linux 部署及备份升级验收属于后续工单，本票没有将它们标为完成。原型 4317 未改动，未部署、推送或合入集成分支。
