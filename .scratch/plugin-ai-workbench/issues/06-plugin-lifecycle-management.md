- [x] 当前提供者失效时按显式兼容回退或最小故障页恢复；根布局、登录、管理 UI 皆不可用时仍可经服务器本地维护修复。仅管理 UI 故障不阻断其他已认证可用视图或服务器运行。纯 UI 停用不删除历史、不停止 Run、不响应 Interaction；可信同源 UI 不宣称为恶意代码沙箱。

- [x] 通过配置、启停、故障归档和浏览器验证；完整受影响 Run 排空在维护工单接入。
