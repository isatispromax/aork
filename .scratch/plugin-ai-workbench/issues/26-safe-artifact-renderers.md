# 26: 可扩展且隔离的产物预览

**What to build:** 安装 renderer 后可预览对应 Artifact，生成的 HTML 无法使用工作台身份，renderer 故障局部可恢复。

**Blocked by:** 25: 登记、预览和下载产物版本

**Status:** ready-for-agent

- [ ] 按 MIME 和已安装贡献点选择 renderer，停用后回退文件信息及下载，不修改 Artifact 原始版本。
- [ ] 主动 HTML 使用不带同源权限的受限 iframe；需要复杂交互时必须独立来源和专门协议，不能复用带会话 Cookie 的主站。
- [ ] 不开放能恢复同源工作台权限的 sandbox 组合，预览内容不能读取凭据或替用户执行工作台命令。
- [ ] renderer 激活、撤销和错误边界复用 Plugin 生命周期，单个 renderer 故障不破坏历史和其他视图。
- [ ] 通过实际浏览器加载受控主动内容、失败 renderer 和未知 MIME 验证隔离、回退及重启后版本访问。

- [ ] renderer 使用版本化公开 UI 契约；同 MIME 存在多个候选时由 profile 显式选定，不按注册顺序覆盖。预览容器也可替换，但不得取消主动内容隔离或绕过服务端授权下载。

规格用户故事：49, 51, 55, 69, 74。

验收共识：遵循正式规格、领域词汇与已接受 ADR（含全界面公开替换契约 ADR-0004）；使用真实 Host、插件和持久化，经浏览器或公开命令/查询/事件及维护入口验证外部行为。ACP 协议替身仅用于外部 Agent 与故障控制，真实 Agent 验收不得被替代。
