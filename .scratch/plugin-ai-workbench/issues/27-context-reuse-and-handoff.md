# 27: 复用成果与关联新会话

**What to build:** 用户选择文件、摘要或 Artifact 版本继续工作，或切换 Agent 创建带来源关联的新 Session。

**Blocked by:** 17: 按 Agent 能力配置输入和参数, 25: 登记、预览和下载产物版本

**Status:** ready-for-agent

- [ ] 从现有结果或不可恢复历史进入关联新会话，选择目标 Profile/Workspace，并明确选取携带内容。
- [ ] 保留旧 Session 和来源关系，不跨 Provider 复用原生会话 ID，不宣称无损上下文迁移。
- [ ] 同一会话也可把 Artifact 版本再次作为输入，服从 Agent 协商能力和访问范围；大内容通过受控引用处理。
- [ ] 只携带用户选择的内容，版本不存在、无权限或输入不支持时给出可修正错误；重试命令不重复创建 Session/Turn。
- [ ] 浏览器验证同会话复用、换 Provider、无原生恢复能力和错误引用；本票不依赖原生恢复实现完成。

规格用户故事：41, 42, 50。

验收共识：遵循正式规格、领域词汇与已接受 ADR（含全界面公开替换契约 ADR-0004）；使用真实 Host、插件和持久化，经浏览器或公开命令/查询/事件及维护入口验证外部行为。ACP 协议替身仅用于外部 Agent 与故障控制，真实 Agent 验收不得被替代。
