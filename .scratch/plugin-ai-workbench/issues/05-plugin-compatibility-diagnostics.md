# 05: 插件兼容性检查与失败诊断

**What to build:** 安装或启用不兼容插件时，维护者看到具体 SDK、依赖、配置或服务冲突，原工作台仍可启动。

**Blocked by:** 04: 独立安装一个服务与界面插件

**Status:** resolved

- [x] 校验插件版本、SDK 范围、服务契约主版本、必需与可选依赖、配置 schema，以及单实例与多 Provider 语义。
- [x] 依赖图检测缺失与环；声明宿主能力不等于自动授权；配置和权限不满足时不激活入口。
- [x] 预检失败保留原 profile 与已安装有效图，CLI 和受保护诊断页面呈现对应包及修复原因。
- [x] 插件只使用公开 SDK 和所需业务契约，不通过包内部导入或裸数据库连接跨所有权访问。
- [x] 校验 UI 契约版本、共享运行时、提供者和扩展目标、服务依赖及能力；重复 ID、无效目标、必需界面未选提供者和不兼容选择均报告具体包／契约。多个候选由 profile 显式选择，禁止 last-registration-wins。
- [x] profile 配置的回退提供者也需预检；未知或失效目标不能静默换成任意已安装 UI。失败保留原可用组合，公开诊断能说明修复动作。
- [x] 用独立错误归档和浏览器诊断验证失败与修正后安装，不围绕内部依赖解析函数写实现镜像测试。
