# 04: 独立安装一个服务与界面插件

**What to build:** 固定 Host 构建后另行打包 server＋UI Plugin，在空白验收实例初始安装，启动后使用其页面和服务。

**Blocked by:** 03: 访问 Token 与浏览器会话

**Status:** claimed

- [ ] 插件输出独立预构建 ESM、显式 CSS 和清单，不修改 Host 源码、不重新编译工作台即可装配；纯 JS 依赖自包含。
- [ ] 早期安装仅用于新的空白、可丢弃验收实例：先装初始 profile，再启动 Host 并使用 Token 链接访问；检测到已有认证／浏览器会话状态、业务数据、Run 历史或需要迁移即拒绝。不能仅以 Host 已停止认定旧进程/工具已经停止；已有实例安装必须等待完整维护安装工单。
- [ ] 归档路径、入口、资源和 SDK 基本信息先校验；拒绝越出包目录、外部入口、未知原生 addon、重复 React 和不支持共享入口。
- [ ] 浏览器从当前图加载同源内容哈希资产，共享 React、React DOM、Aork 客户端与 UI runtime，设置结果可经插件服务保存并重启读取。
- [ ] 独立包可声明并被 profile 选为主布局或登录／设置视图提供者，同时贡献可排序／隐藏的扩展项；不能仅新增面板就宣称支持替换。默认组合与独立包使用相同 UI 契约，不导入宿主私有组件树。
- [ ] UI 提供者选择、扩展顺序／显隐、主题和图标配置纳入当前图；安装只增加候选，不以注册顺序覆盖默认界面。沿用本票空白实例限制，已有实例的组合变更等待维护安装工单。
- [ ] 启动返回 Host 代次、插件图与 API 版本；旧页面命令得到 RELOAD_REQUIRED 且不执行，刷新后恢复。
- [ ] 通过独立构建、公开安装 CLI、浏览器和公开服务验证，不能将静态编入 Host 的模块作为通过证据。

规格用户故事：57, 68, 69, 73, 75, 76, 77。

验收共识：遵循正式规格、领域词汇与已接受 ADR（含全界面公开替换契约 ADR-0004）；使用真实 Host、插件和持久化，经浏览器或公开命令/查询/事件及维护入口验证外部行为。ACP 协议替身仅用于外部 Agent 与故障控制，真实 Agent 验收不得被替代。
