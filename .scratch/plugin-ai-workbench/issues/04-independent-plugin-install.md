**Status:** resolved

- [x] 插件输出独立预构建 ESM、显式 CSS 和清单，不修改 Host 源码、不重新编译工作台即可装配；纯 JS 依赖自包含。

- [x] 归档路径、入口、资源和 SDK 基本信息先校验；拒绝越出包目录、外部入口、未知原生 addon、重复 React 和不支持共享入口。

- [x] UI 提供者选择、扩展顺序／显隐、主题和图标配置纳入当前图；安装只增加候选，不以注册顺序覆盖默认界面。沿用本票空白实例限制，已有实例的组合变更等待维护安装工单。
- [x] 启动返回 Host 代次、插件图与 API 版本；旧页面命令得到 RELOAD_REQUIRED 且不执行，刷新后恢复。
- [x] 通过独立构建、公开安装 CLI、浏览器和公开服务验证，不能将静态编入 Host 的模块作为通过证据。
