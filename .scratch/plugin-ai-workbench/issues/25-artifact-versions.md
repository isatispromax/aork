# 25: 登记、预览和下载产物版本

**What to build:** 用户显式登记工作结果为 Artifact，查看来源和版本，预览基础文本或下载未知格式文件。

**Blocked by:** 12: 完成文本执行轮次并随时取消

**Status:** ready-for-agent

- [ ] Artifact 显式登记而非自动把全部工作区文件归因于 Agent；版本关联 Project、来源 Session/Turn 及内容引用。
- [ ] 内容版本不可变，外部引用明确标识；可变工作区文件与导出版本区分。
- [ ] 文件经临时写入、完整校验和原子改名后登记元数据；失败不产生虚假成功，孤立内容可回收，不假装文件与数据库同一事务。
- [ ] 基础文本预览、版本选择、文件信息与授权下载贯通浏览器和公开接口，未知格式始终有下载途径。
- [ ] 通过实际文件变更与重复登记命令验证版本稳定、来源、幂等、失败和引用保护；归档不级联删除仍被引用的版本。

- [ ] 产物列表、版本选择与基础预览使用公开 UI 契约，替换 UI 仍调用 artifacts 的查询／下载入口，保留稳定版本及来源，不将元数据或领域存储转交视图所有。

规格用户故事：47, 48, 49, 74。

验收共识：遵循正式规格、领域词汇与已接受 ADR（含全界面公开替换契约 ADR-0004）；使用真实 Host、插件和持久化，经浏览器或公开命令/查询/事件及维护入口验证外部行为。ACP 协议替身仅用于外部 Agent 与故障控制，真实 Agent 验收不得被替代。
