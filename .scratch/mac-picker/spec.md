# 自绘 macOS 风格目录选择器重做（修正方向）

Status: resolved
日期：2026-11-22
范围：目录选择器呈现层重做 + 撤销 osascript 原生方案；access 移除维持

修订 `.scratch/native-picker/spec.md` 的方向：用户澄清要的是**自己实现的类 Mac 文件夹选择器**，不是调起系统原生对话框（`osascript choose folder` 方案整体撤销）；「访问权限不要」维持已删除状态。第一版自绘选择器被评价为「和 mac 的文件选择器不一样」，问题在保真度：纯文字列表、无图标、无工具栏、无键盘导航，观感是普通网页表格。

## Solution

1. **撤销原生方案**：删除 `pick.ts`、`workspace.pickDirectory` 资源与契约；恢复 `browse.ts`、`workspace.browseDirectory` 资源与 `BrowseDirectory` 契约（与 workspace-first 版本一致）。
2. **选择器呈现层重做**（`directory-picker.tsx` + CSS 全量重写，纯函数与交互语义不变）：
   - 窗口 chrome：标题栏（居中标题「选择文件夹」+ 功能性红绿灯：红=取消，黄/绿禁用态）；
   - 工具栏：Finder 式返回/后退历史（前进尾截断语义）+ 圆角搜索框（当前目录客户端过滤，实时）；
   - 收藏栏：主目录/桌面/文稿/下载 四项带图标，当前项高亮；前往文件夹（⇧⌘G）与显示隐藏文件保留在侧栏；
   - 列表：文件夹/文件/链接 SVG 图标、目录优先、蓝色选中行（白字）、文件行灰显不可选；
   - 键盘：↑/↓ 移动选择（滚动跟随），→ 进入选中目录，← 返回上级，Enter/双击进入，Esc 取消；
   - 底部路径栏（分段可点 + 项目计数）+ 底部操作行（取消/选择，左下显示将确认的路径）。
3. **表单**：目录回到「选择目录…」入口 + 路径展示；确认后名称为空时自动填目录名（保留）。无权限选择、无授权勾选。
4. **保留**：双实例 overview 补拉修复（native-picker 02 发现的先期缺陷）；全部 access 移除。

## 明确不做

- 不做列视图/分栏浏览、type-ahead、iCloud/隔空投递等收藏项；后续按反馈再加。
- 不恢复只读工作区；不做选择器内新建文件夹。
